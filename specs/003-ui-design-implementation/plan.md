# Implementation Plan: Advantage Design System

**Branch**: `003-ui-design-implementation` | **Date**: 2026-04-28 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/003-ui-design-implementation/spec.md`

## Summary

Apply the Advantage Design System handoff bundle to the existing React/Vite/TypeScript codebase. The redesign replaces the original clay-orange + bright-green palette with Deep Forest Green / Cool Slate Gray / Off-White Bone, swaps all emoji for SVG stroke icons, introduces Fraunces display and JetBrains Mono fonts, changes category chips to outlined capsules, and upgrades the Today view to show three consecutive day cards (prev / selected / next). No data model or localStorage schema changes are required.

## Technical Context

**Language/Version**: TypeScript 5.x  
**Primary Dependencies**: React 18, Vite 5, Tailwind CSS 3 (extended with new tokens), Recharts (charts)  
**Storage**: `localStorage` only — no schema changes in this feature  
**Testing**: Vitest (existing setup); visual verification in browser required per constitution  
**Target Platform**: Browser SPA, mobile-first (390px viewport baseline)  
**Project Type**: Mobile-first single-page web application  
**Performance Goals**: FCP < 2s on WiFi; fonts loaded from CDN cache on repeat visits  
**Constraints**: Offline-capable after initial load; CSS font fallbacks defined for offline; no backend; static build only  
**Scale/Scope**: Single user, ~10 screens, 50 exercises across 5 categories
